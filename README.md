Link to ThinkBot: https://thinkbot-test.vercel.app/login 

Before using ThinkBot, you need to first click on 'Har du ikke en konto? Opret en' or 'Don't have an account? Create one' 
and sign up using an e-mail address and creating a password.

Link to teacher report module: https://thinkbot-test.vercel.app/rapport
Password to teacher report module: Thinkbot2026  

In the upper right corner of the sign-up/login page, there is an option to switch between Danish and English; 
however, this only changes the language in the app interface and not the language ThinkBot uses in messages. 
As this would have required us to reconfigure the language options in SupaBase.
